# 04. Кросс-тулчейн

Соответствует: **LFS Chapter 5 — Compiling a Cross-Toolchain**  
Скрипт: `scripts/02-toolchain-cross.sh`  
Пользователь: **lfs**

## Идея главы

Нужно собрать инструменты, которые:

- запускаются на **хосте**
- производят бинарники для **будущей** системы (`$LFS_TGT`)

Результат кладётся в `$LFS/tools` и частично в `$LFS/usr`.

## Порядок сборки (критичен!)

```text
1. Binutils (pass 1)
2. GCC (pass 1)          # без полноценной libc
3. Linux API Headers
4. Glibc                 # C-библиотека будущей системы
5. Libstdc++             # из исходников GCC
```

Почему так:

1. Линкер/ассемблер нужны раньше компилятора  
2. GCC pass 1 — минимальный кросс-компилятор  
3. Заголовки ядра нужны glibc  
4. Glibc — сердце userspace  
5. Libstdc++ нужен некоторым пакетам дальше  

## Что делает скрипт

```bash
su - lfs
bash /path/to/repo/scripts/02-toolchain-cross.sh
```

Он:

- проверяет `$LFS`
- распаковывает тарболы из `$LFS/sources`
- собирает пакеты с флагами LFS-стиля
- чистит каталоги исходников после установки

### Важные флаги (смысл)

| Флаг | Зачем |
|------|-------|
| `--prefix=$LFS/tools` | Установка кросс-инструментов |
| `--target=$LFS_TGT` | Цель кросс-компиляции |
| `--with-sysroot=$LFS` | Корень «будущей» FS |
| `--disable-nls` | Без локализации (упрощает раннюю сборку) |
| `DESTDIR=$LFS` (для glibc) | Файлы попадают в дерево будущей ОС |

## Сколько времени

Обычно **4–8 часов** (зависит от CPU VM). GCC и Glibc — самые долгие.

Совет: используй `tmux`/`screen`, чтобы SSH-обрыв не убил сборку.

## Как понять, что успех

```bash
ls $LFS/tools/bin
$LFS_TGT-gcc --version
ls $LFS/usr/include/stdio.h
ls $LFS/usr/lib/libc.so*
```

Должны появиться кросс-утилиты (`x86_64-lfs-linux-gnu-gcc` и т.д.) и файлы glibc под `$LFS`.

## Типичные ошибки

| Ошибка | Причина | Что делать |
|--------|---------|------------|
| `C compiler cannot create executables` | Сломан PATH / нет pass1 | Проверь `.bashrc` lfs, пересобери с начала главы |
| Нет `mpfr/gmp/mpc` внутри GCC | Не распакованы рядом с gcc | Скрипт делает это сам; при ручной сборке — обязательно |
| Патч glibc не применяется | Нет файла патча в sources | Перекачай `glibc-*-fhs-1.patch` |
| Сборка упала на середине | Нехватка RAM/диска | Добавь swap/место, повтори пакет |
