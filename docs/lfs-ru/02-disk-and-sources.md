# 02. Диск и исходники

Соответствует: **LFS Chapters 2.3–3**  
Скрипты: `scripts/01-prepare-disk.sh`, `sources/download.sh`

## Переменная `$LFS`

Во всей книге LFS используется:

```bash
export LFS=/mnt/lfs
```

Это **точка монтирования** будущего корня `/` твоей системы. Пока ты на хосте, всё, что ставится «в новую ОС», идёт под `$LFS/...`.

После `chroot` эта переменная уже не нужна: внутри chroot путь `/` и есть твоя система.

## Требование ft_linux: 3 раздела

Минимум:

| Раздел | FS | Точка монтирования | Размер (пример) |
|--------|----|--------------------|-----------------|
| 1 | ext2 | `/boot` | ~500 MB |
| 2 | ext4 | `/` | остаток диска |
| 3 | swap | — | ~2 GB |

Почему `/boot` отдельно: проще для GRUB и соответствует заданию.

## Разметка (логика)

Скрипт `01-prepare-disk.sh` делает примерно следующее:

1. Создаёт MBR (msdos) таблицу
2. Режет разделы
3. Форматирует: `mkfs.ext2`, `mkfs.ext4`, `mkswap`
4. Монтирует root в `$LFS`, boot в `$LFS/boot`
5. Включает swap

```bash
sudo bash scripts/01-prepare-disk.sh /dev/sda
```

**Внимание:** скрипт уничтожает данные на диске. Подтверждение — только `YES`.

После успеха:

```text
/boot  -> /dev/sda1
/      -> /dev/sda2   (смонтирован в /mnt/lfs)
swap   -> /dev/sda3
```

Проверь:

```bash
echo $LFS
df -h | grep lfs
swapon --show
```

## Структура каталогов до сборки

Минимум:

```bash
mkdir -pv $LFS/sources
mkdir -pv $LFS/tools
```

- `$LFS/sources` — все `.tar.xz` / `.tar.gz` / патчи  
- `$LFS/tools` — кросс-тулчейн (глава 5)

## Скачивание исходников

В репозитории уже есть:

- `sources/wget-list.txt` — URL пакетов LFS 12.4 SysV  
- `sources/md5sums.txt` — контрольные суммы  
- `sources/download.sh` — скачивание + проверка

На Mac или на хосте VM:

```bash
bash sources/download.sh
```

Потом скопируй тарболы:

```bash
cp -v sources/*.{tar.*,tgz,patch} $LFS/sources/
```

Или качай сразу в `$LFS/sources`.

Объём ≈ **1.5 GB**. Без полного набора сборка остановится на первом же отсутствующем пакете.

## Проверка целостности

```bash
cd $LFS/sources
md5sum -c /path/to/repo/sources/md5sums.txt
```

Несовпадение MD5 = битый файл. Удали его и перекачай.

## FHS (кратко)

LFS и ft_linux требуют иерархию в духе FHS:

| Путь | Назначение |
|------|------------|
| `/bin`, `/sbin`, `/usr/bin` | программы |
| `/etc` | конфигурация |
| `/lib` | библиотеки |
| `/boot` | ядро и GRUB |
| `/var` | логи, spools |
| `/home`, `/root` | домашние каталоги |
| `/proc`, `/sys`, `/dev` | виртуальные FS ядра |

Полное дерево создаст `04-chroot-setup.sh`.

## Типичные ошибки

| Проблема | Решение |
|----------|---------|
| `$LFS` пустой после reboot хоста | Добавь `export LFS=/mnt/lfs` в `~/.bashrc` и смонтируй разделы снова |
| `No space left on device` | Мало места / забыли отдельный большой root |
| SourceForge timeout | Повтори `download.sh` — он умеет resume |

- Диск размечен и смонтирован  
- `$LFS` задан  
- Исходники лежат в `$LFS/sources` и проходят md5
